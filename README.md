# OpenMAP-T1c

OpenMAP-T1c has been integrated into [OpenMAP-T1](https://github.com/OishiLab/OpenMAP-T1). This repository is no longer maintained.

Both OpenMAP-T1 and OpenMAP-T1c now run from that repository:

**https://github.com/OishiLab/OpenMAP-T1**

Select OpenMAP-T1c with `-m model/OpenMAP-T1c` or `--mode t1c`.
