# OpenMAP-T1c

OpenMAP-T1c は [OpenMAP-T1](https://github.com/OishiLab/OpenMAP-T1) に統合されました。このリポジトリはメンテナンスを終了しています。

OpenMAP-T1 と OpenMAP-T1c の両方は、次のリポジトリから実行できます。

**https://github.com/OishiLab/OpenMAP-T1**

OpenMAP-T1c は `-m model/OpenMAP-T1c` または `--mode t1c` で選択します。

---

OpenMAP-T1c has been integrated into [OpenMAP-T1](https://github.com/OishiLab/OpenMAP-T1). This repository is no longer maintained.

Both OpenMAP-T1 and OpenMAP-T1c now run from that repository. Select OpenMAP-T1c with `-m model/OpenMAP-T1c` or `--mode t1c`.
